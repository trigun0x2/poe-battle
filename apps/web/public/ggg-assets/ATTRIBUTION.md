# GGG-derived assets

This directory is the **only** place Grinding Gear Games–derived art may
live, so it can be attributed and swapped wholesale.

- v1 ships **no** GGG assets: all cards are typographic, all glyphs are
  original.
- If art is added later, it must comply with the
  [Grinding Gear Games fan content policy](https://www.pathofexile.com/legal/terms-of-use-and-privacy-policy),
  be listed in this file with its source, and never be required for the game
  to function (the typographic fallback stays).
